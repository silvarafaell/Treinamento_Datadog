Curso Treinamento Datadog no nextwave(LuisDEV)

- Datadog, new relic e data trace são consideradas as três melhores ferramentas mas é pago
- Criar Conta Datadog
  - Crie sua conta gratuitamente em https://www.datadoghq.com/product/
  - Essa conta é grátis por 14 dias com algumas limitações
  - Datadog, assim como a maioria dos APM tools na atualidade, é SaaS. Ou seja, não precisa ser instalado localmente, sendo acessível através da internet

- Setup de ambiente (Homework)
  - Instalar o Infrastructure agent usando o Guided install
  - Copiar e salvar a chave de acesso à API do Datadog como mostra essa doc
  - Requisitos
    - Ter acesso de admin ao seu laptop
    - Linux, Macos ou Windows
    - Ter git e docker instalado
    - Ter dotnet, java, jdk, golang ou python instalados
    - VsCode ou uma IDE qualquer
 - Acessar essa doc para aprender como instrumentar uma aplicação
   - Existem diversas maneiras de instrumentar apps com o Datadog, dentre esta, algumas das opções aconselhadas são: autoinstrumentação, instrumentação manual do agent dd ou OpenTelemetry
 - Ou, escolher uma opção entre as demo apps, podendo ser python, java, php e golang,  aplicar os passos contidos no README.md dentro do diretorio da respectiva linguagem
